## 八、已知限制（必须与成绩一起看）

1. **合成数据**：全部由脚本生成，句式与字段位置比真实标书规整，解析与抽取成绩会偏高；
2. **同分布**：holdout 与 dev 同源同分布，只能证明规则没有过拟合到单份文件，不能证明真实泛化；
3. **覆盖有限**：集中于货物 / 服务 / 工程三类的投标文件侧，未覆盖招标文件侧、资格预审文件、附件清单；
4. **扫描件来源**：由 docx→pdf→图像→无文本层 PDF 转制，清晰度高于真实扫描件，OCR 成绩偏乐观；
5. **风险样本单点植入**：每份只植入一类风险，真实文档常多风险并存，检出率会低于本报告。

## 九、合规声明

- 主体名称均为虚构（示例市公共资源交易中心、示例数智科技有限公司等），与真实单位无关；
- 金额、编号、工期为编造值，不构成任何真实交易信息；
- 样本仅用于本项目评测与演示，可随仓库以 MIT 协议分发。
