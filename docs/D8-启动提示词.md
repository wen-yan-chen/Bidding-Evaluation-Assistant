## 2. D8 范围（六件事，按此顺序）

1. **评审页**：上传文件 → 选评分细则（profile-a / profile-b）→ 触发评审 → 结果展示
   （顶部总分卡：总分/满分、资格性计数、风险计数、细则指纹；下方三栏：资格性表 / 分项评分表 / 风险清单）
2. **双栏对照**：左栏按页渲染原文（`/api/doc/{id}` 的 `pages` 切片），右栏结果列表；
   点击任一条风险或字段 → 左栏滚动到对应页并用 `<mark>` 高亮 `quote`
3. **报告中心**：列出最近评审（`GET /api/review`），每行「生成/下载 docx」「下载 pdf」按钮，
   下载走后端 `GET /api/report/{id}?format=docx|pdf`；显示文件大小与数值摘要（`/meta`）
4. **换细则入口**：页面上切换 `profile_id` 后重新评审，**分项分数必须可见变化**（68 → 62）
5. **免责 banner**：顶部常驻「AI 辅助评审结果，最终以评标委员会评审结论为准」（一字不差）
6. **状态与错误**：上传失败、解析 failed、评审 404、报告未生成等都要有可读提示；空态不要空白页

- **不新增后端业务逻辑**：前端只调用现有接口；确需新接口时（例如列报告文件），先说明理由再最小化实现
- **不要占位按钮**：任何按钮都必须有真实行为；未完成的功能标注「待 D9」而不是做成点了没反应

- 前端自包含（无 CDN、无外链字体），中文 UI，支持 1280–1920 宽度，打印样式可读
- 不改动平台侧（Nexent）数据库与知识库；不提交 `.env`
- 保持既有测试与冒烟全绿；新增前端行为尽量用「接口已有断言」覆盖

## 7. 已知坑（别踩）

| 坑 | 说明 |
| --- | --- |
| 端口 | 本机 8080 被 32 题容器占用，一律用 **18080**；文档里默认仍写 8080（他人环境） |
| docx 页码 | docx 无分页符时页码是按行估算（`page_source=estimated`），跳转允许偏 1 页，页面上要标注「估算」 |
| 扫描件慢 | 单份 3 页扫描件 13–16 s，前端要有 loading 与超时提示，不要让人以为卡死 |
| 报告幂等 | 同一 `review_id` 重复导出返回同一文件；改了数据要换新评审再导出 |
| PDF 字体 | 报告 pdf 用 reportlab 内置 CID 字体，个别极简阅读器可能替换字形，但不影响文本与数值 |
| 大文件 | 上传上限 50 MB（`MAX_UPLOAD_MB`），超了要给出可读错误而不是 500 |
