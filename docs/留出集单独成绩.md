## 四、限制（必须与成绩一起看）

1. **合成数据**：样本由脚本生成，句式与字段位置比真实标书规整，解析与抽取成绩偏高；
2. **同分布**：holdout 与 dev 同源同分布，只能证明规则没有过拟合到单份文件，不能证明真实泛化；
3. **单点植入**：每份风险样本只植入一类风险，真实文件常多风险并存，检出率会低于本表；
4. **扫描件来源**：docx→pdf→图像→无文本层 PDF，清晰度高于真实扫描件，OCR 成绩偏乐观；
5. **专家评分缺失**：没有真实专家双盲评分，评分偏差 ±5 分比例未计算（见 `docs/TEST_REPORT.md` §4.3）。
