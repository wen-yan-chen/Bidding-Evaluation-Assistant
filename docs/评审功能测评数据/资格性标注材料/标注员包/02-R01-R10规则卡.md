# R01–R10 资格性规则卡（人工标注用）

> 只判断“投标文件里写没写、写的是否无效”，不判断证件真伪、不判断业绩真实性。
> 全部按原文；不要用项目类型推断“应该有什么”。

## 判断顺序（建议）

1. 先找该材料/章节/声明是否存在；
2. 不存在 → **缺失**；
3. 存在但同一句有“过期/失效/无效/不满足/不具备/不符合” → **效力不足**；
4. 存在且没有否定 → **已提供**；
5. 看不清/语义不明 → **无法判断**，备注写原因。

## 容易错的点

- **R07 的“无重大违法记录”不是“效力不足”**：这是合规声明，填“已提供”；
- **“无需提供”不是“效力不足”**：填“缺失”，备注“不适用”；
- **“未提供营业执照”不是“效力不足”**：填“缺失”；
- **“营业执照已过期”才是“效力不足”**；
- **不要因为“招标文件要求”就填已提供**：投标文件没写，就是缺失；
- **扫描件看不清**：填“无法判断”，不要猜；
- **不要看算法结果、不要和另一位标注员讨论**。
