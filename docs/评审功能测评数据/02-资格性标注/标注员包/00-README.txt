资格性人工标注包（R01–R10，25 份样本）
========================================

谢谢你帮忙！你只需要做一件事：按原文给每份投标文件的 10 项资格材料选状态。

时间：约 2–3 小时，可以分 2–3 次做。
任务：25 份样本 × 10 条 = 250 行；每行选一个状态：
  已提供 / 缺失 / 效力不足 / 无法判断

先看：
  01-标注说明.md       （怎么填、四个状态）
  02-R01-R10规则卡.md  （每条材料看什么）
  04-样本清单.csv      （S01–S25 的格式/页数）

填写：
  打开 03-标注表_A.xlsx（或 _B），只填“状态/页码/原文备注”三列；
  状态是下拉框；不确定就选“无法判断”，在备注写原因。

注意：
  - 只看原文，不要搜索、不要用算法结果、不要和另一位标注员讨论；
  - “未提供营业执照”填“缺失”，不是“效力不足”；
  - “无重大违法记录”是合规声明，R07 填“已提供”；
  - “无需提供”填“缺失”，备注写“不适用”；
  - 样本全部是虚构数据，不含真实企业/个人信息。

交回：
  把填好的 03-标注表_A.xlsx（或 _B）发回即可；不用改文件名。
  谢谢！
