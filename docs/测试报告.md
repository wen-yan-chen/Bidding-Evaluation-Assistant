## 七、局限与如实披露

1. **评分“专家”为单评审人盲评**（n=10），不是多专家一致性结论；校准在同一批 N01–N10 上完成，**10/10 属拟合内成绩**，不能当作泛化准确率；95% 置信区间约 72%–100%。
2. N01–N08 的 T1/T3/T4 文本相同、恒为 24 分，这三项对样本区分力有限；N09/N10 已加入“有/无”对照。
3. 样本为脚本生成的合成数据，句式与字段位置比真实标书规整，解析与抽取成绩偏乐观；扫描件由 docx→pdf→图像转制，清晰度高于真实扫描件。
4. R25/R32/R33 需多家投标人比价，单份不可判定；4 条经验型规则（R30/R31/R33/R40）无直接法规条号，标注为 `na`。
5. 3 次一致性验证覆盖确定性链路（解析 / 资格性 / 评分 / 风险），不覆盖 LLM 生成的自然语言表述；报告数字只来自工具返回。
6. LLM 对话链路的首字与端到端未单独计时；上文时延为确定性 API 与页面渲染的实测值。
7. 容器 67 passed 为 2026-11-17 记录值，本机 Docker 管道当前不可用，未在本次复跑。
