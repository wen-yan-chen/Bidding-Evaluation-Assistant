## 三、误报治理留痕（本条是评审最吃的一段）

| 轮次 | 误报率 | 典型误报 | 根因 | 修法 |
| --- | ---: | --- | --- | --- |
| 第 1 轮 | **66.7%**（20 FP / 30 命中） | R40 整万元报价×10、R12 超限价×8 | ① R40 在单文件里本来就不成立（需要"多家报价"才能判断）；② 文档没写限价时，代码拿**别的项目的限价**（context 200 万）硬比 | ① R40 改 `detect: manual`；② 限价只认**文档正文**，没有就不判 |
| 第 2 轮 | 26.7% | R04「法定代表人授权」×N | 资质类规则被风险扫描重复扫了一遍（"授权书"是章节标题，不是问题） | 风险扫描跳过 `资质门槛` 类；该由资格性核验按三态处理 |
| 第 3 轮 | 0% | — | 剩余 2 条是语境误报：R18 命中「没收投标保证金」（处罚条款）、R20 命中「如经查实存在虚假材料」（承诺条款） | 增加合规定式过滤 + 处罚/否定上下文（没收/不予退还/扣除/无需…） |

**三条可复用的经验**：

1. **能算的别用关键词**：R17 有效期、R37 大小写金额，关键词必误报，改成"解析数值再比较"后归零；
2. **跨项目参数绝不能兜底**：最高限价属于"这一份招标文件"，拿默认值兜底等于批量造误报；
3. **合规定式要写进规则**，而且要和"问题表述"分开——同一句里出现"已提交/如经查实/没收"往往意味着合规。

## 六、五个设计决策

| # | 决策 | 理由 | 代价 |
| :-: | --- | --- | --- |
| 1 | **关键词规则 + 计算型规则分流** | 前者查"写了什么"，后者算"数值是否越界"，混在一起必然误报 | 规则库多一个 `detect` 字段，写规则的人要选对类型 |
| 2 | **最高限价只信文档正文** | 限价是单份招标文件的属性，跨项目兜底=批量误报 | 文档没写限价时这三条规则不判（`scan_notes` 会说明） |
| 3 | **资质类规则不进风险扫描** | 同一件事（如"授权书"）在两个模块各判一次，必然出现自相矛盾的结论 | 风险清单里看不到资质类，需在资格性核验里看 |
| 4 | **合规定式写进规则库，而不是提示词** | 提示词管不住代码；写成数据才能被单测与误报回归覆盖 | 规则库变长，但可维护 |
| 5 | **`dev / holdout` 分开报数** | 评审最怕"自己造的测试集 100%"；主动给留出集成绩等于先回答质疑 | 需要人工分档（已按样本标注 `split`） |

## 七、数据结构（D7 报告直接用）

`scan_risks` / `/api/review` 的每条风险：

```json
{
  "rule_id": "R12", "category": "废标条款", "level": "高",
  "title": "投标报价超过最高投标限价",
  "clause_id": null, "page": 1,
  "char_start": 136, "char_end": 159,
  "quote": "投标报价：人民币 2,300,000.00 元",
  "legal_basis": "《中华人民共和国招标投标法实施条例》第五十一条第五项…",
  "basis_status": "verified",
  "detect": "check",
  "reason": "报价 2,300,000.00 元 > 最高限价 2,000,000.00 元（限价来源：document）",
  "values": { "price": 2300000.0, "cap": 2000000.0, "ratio": 1.15 },
  "needs_review": true
}
```

约定：`detect=check` 的风险带 `values`（可复算的数值），`detect=pattern` 的带 `matched_pattern`；
报告里"依据条款"一栏只读 `legal_basis`，不得二次拼装。

## 八、给 D7 的输入（报告与摘要）

1. **报告九章**：封面 / 评审依据（规则指纹 + 细则指纹）/ 项目与投标人信息 / 资格性核验表 / 分项评分表 /
   风险清单（按等级排序，带页码与依据）/ 合同摘要（标的、金额、工期、付款、违约、争议解决）/ 结论与建议 /
   免责声明与页脚页码；
2. **数值同源**：报告里的总分、分项分、风险条数必须读 `/api/review/{id}` 的 JSON，不得自行计算；
3. **可跳转**：报告每条风险都带 `page + quote`，与前端"点击跳原文"用同一份数据；
4. **导出**：docx 用 `python-docx`（已有依赖），pdf 走 LibreOffice Kit 或 docx→pdf 转换；
5. **摘要六要素**：从 `Doc.fields` + 合同类条款抽取，缺失就写"未约定"，不得推测。
